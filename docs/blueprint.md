# **App Name**: ENURM Ace

## Core Features:

- Landing Page: Implement landing page with clear call to action to 'Start Practicing'
- Practice Questions: Allow users to practice with questions with multiple choice questions pulled from stored JSON.
- Show Results: Show results of questions after user answers, then track the data of each test.
- Varied study modes: Provide multiple study modes to cater different scenarios like Quick Practice, Review, Exam Simulation and more.
- Authentication: Enable sign-in using 3rd party authentication provider such as Google, Apple or Email.

## Style Guidelines:

- Use a clean, professional color palette to inspire trust. Use shades of blues and greys.
- Accent color: Teal (#008080) for key interactive elements and highlights.
- Use clear, readable fonts for all text elements. Prioritize legibility for exam questions.
- Incorporate easily recognizable icons that provide quick guidance and represent different app sections.
- Ensure a well-structured and intuitive page layout with a clear information hierarchy for easy navigation.
- Incorporate subtle transitions when showing or dismissing feedback on questions, revealing answers, or transitioning between study modes.
